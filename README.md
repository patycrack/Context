# Rick and Morty App

This site allows you to browse the most popular characters from the public Rick and Morty API. You can also get to know each character better on their detailed card. A search engine is included to filter characters. The layout is fully responsive and designed to mimic Tailwind CSS utilities for a clean, modern look.

## Technologies

- React Vitae
- React Hooks
- React Router
- React Context
- Axios
- Public API (fetch)
- JavaScript: ES6+
- Responsive Web Design
- Tailwind CSS (simulated through custom CSS)

## NOTES

I implemented a loading overlay with a spinning image to enhance the user experience while data is being fetched. I applied global state management using React Context to handle the list of characters and the loading state efficiently. This project allowed me to apply all my knowledge as a junior developer, focusing on clean code, component-based architecture, and responsiveness across devices.
